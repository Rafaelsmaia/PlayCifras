Configurações

As abas Diagramas e Letra usam o site no ar e o ajudante de render instalado neste PC (npm run helper:install). A aba Shorts ainda precisa do npm run dev.

Clique num acorde para começar a partir dele.

Clique na linha onde o seu trecho começa.

Overlay = um .mov transparente (letra + diagrama + marca) em V2, sobre o seu vídeo. Sincronize L/D no editor antes. Render pode levar alguns minutos na 1ª vez.
